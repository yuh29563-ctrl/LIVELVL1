## 使用规则

- 真实产品规则、可访问性和安全区高于图片中的示例文案与示例数字。
- 图片中的概念六维名称必须映射为现有 `LifeDimension` 的真实六维。
- 卡片像素画是艺术方向参考；正式素材应通过 `CollectibleDefinition` 或等价稳定资源替换。
- 不使用这些 PNG 作为整屏背景，不通过截图遮盖实现。
- 视觉验收使用 iPhone 17 Pro 模拟器截图按层级、比例、材质和状态逐项比较，不做跨设备的机械像素差比较。
