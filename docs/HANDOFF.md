## Collection MVP

- 四个 Tab：今天、收集、奖励、我的。奖励页目前仅为占位页；奖励商城尚未实现。
- 等级显示可因撤销任务而下降：`XP < 200` 为 Lv.0；首次到 Lv.1 需要 200 XP；之后每级间隔 2,000 XP（`level = 1 + (XP - 200) / 2000`，当 `XP >= 200`）。
- 收藏进度保存历史最高等级，收藏和当前伙伴不会因 XP 撤销而回退。
- 普通伙伴时间线：Lv.0 为第一只幼体；Lv.1 触发第一只成熟待领取卡；之后每三等级循环为第二形态、第三形态、成熟待领取卡。只有成功“收下”普通成熟卡时，才会归档旧伙伴并出现下一只幼体。
- 两个隐藏发现：首次完成至少 60 分钟的健康行动（长跑鱼），以及连续 3 个不同日历日完成学习行动（书页鸟）。隐藏卡领取不会改变当前普通伙伴。三天规则使用固定日期单元测试夹具验证，并验证重复处理只产生一个奖励键。
- 待领取卡是持久化队列；杀掉 App 后会重新出现，覆盖在当前 Tab 之上但不会切换 Tab。领取会归档卡、给收集 Tab 未查看提示，并播放飞向收集 Tab 的反馈。
- 收集页支持未查看清除、卡片放大/翻面/关闭；图鉴显示已发现卡片与未发现轮廓，隐藏物种在未发现时保持保密。
- Debug 构建的“我的”页提供两次确认的“重置所有本地数据”：清除本地业务数据并回到 Day 0、Lv.0 与第一只幼体。Release 不显示该入口。
