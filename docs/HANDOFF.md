## Collection MVP

- 四个 Tab：今天、收集、奖励、我的。奖励页目前仅为占位页；奖励商城尚未实现。
- 等级显示可因撤销任务而下降：`XP < 200` 为 Lv.0；首次到 Lv.1 需要 200 XP；之后每级间隔 2,000 XP（`level = 1 + (XP - 200) / 2000`，当 `XP >= 200`）。
- 收藏进度保存历史最高等级，收藏和当前伙伴不会因 XP 撤销而回退。
- 普通伙伴时间线：Lv.0 为第一只幼体；Lv.1 触发第一只成熟待领取卡；之后每三等级循环为第二形态、第三形态、成熟待领取卡。只有成功“收下”普通成熟卡时，才会归档旧伙伴并出现下一只幼体。
- 到达成熟等级或启动时补发待领取卡都不会让“今天”的当前伙伴提前显示成熟体；成熟体只出现在奖励卡和已归档卡。延迟领取跨过后续成熟节点时，当前伙伴停在最后一个非成熟阶段。
- 两个隐藏发现：首次完成至少 60 分钟的健康行动（长跑鱼），以及连续 3 个不同日历日完成学习行动（书页鸟）。隐藏卡领取不会改变当前普通伙伴。三天规则使用固定日期单元测试夹具验证，并验证重复处理只产生一个奖励键。
- 待领取卡是持久化队列；杀掉 App 后会重新出现，覆盖在当前 Tab 之上但不会切换 Tab。领取会归档卡、给收集 Tab 未查看提示，并播放飞向收集 Tab 的反馈。
- 已保存的任务完成记录与 XP 会在“今天”出现或 App 回到前台时幂等补发缺失奖励，因此奖励保存失败后重启不会丢卡或生成重复奖励键。
- 收集页只把当前可见、且页面确实已选中并未被奖励层遮挡的卡标为已查看。若在收集页领取，覆盖层消失后才清除新卡的未查看状态；若已离开收集页则保留提示。
- 收集页支持卡片放大/翻面/关闭，关闭后按奖励键把辅助功能焦点还给发起的重点卡或网格卡；图鉴显示已发现卡片与未发现轮廓，隐藏物种在未发现时保持保密。
- 连续奖励不再轮询当前覆盖层；下一张以明确的消失完成时间为基准，最早在 250 ms 后出现。减少动态效果时收集 Tab 反馈仅使用透明度/颜色，缩放保持恒等且不抖动。
- Debug 构建的“我的”页提供两次确认的“重置所有本地数据”：清除本地业务数据并回到 Day 0、Lv.0 与第一只幼体。Release 不显示该入口。

## 最新验证

- 2026-08-24，在 Xcode 26.6、iPhone 17 Pro（iOS 26.5）执行完整 Debug suite：`** TEST SUCCEEDED **`，68 tests / 13 suites，0 failures。独立 Release Simulator 构建为 `** BUILD SUCCEEDED **`。
- 新增聚焦验证先观察到真实 RED（服务组 12 tests 中 4 failures；UI 协调器组在缺少新接口时编译失败），随后服务组 12/12 与组合聚焦组 35/35 全绿。
- 模拟器补验覆盖：Day 0/Lv.0 第一幼体、真实 200 XP 学习任务、领取前旧幼体保持且成熟体只在奖励卡出现、杀掉并重启后待卡重现、开启 Reduce Motion 后领取、真实 60 分钟健康隐藏卡在“收集”已选中时覆盖显示并领取、覆盖层消失后新卡可见且收集标签无未查看提示，以及重点卡展开/关闭后同一卡重新出现在实时辅助功能树。
- iOS 26.5 Simulator 的“辅助功能”设置不提供 VoiceOver 开关，运行时自动化也明确报告卡片元素不暴露 focus 状态，因此无法在该环境声称完成真实 VoiceOver 朗读焦点观测。焦点返回由 `featured/grid + awardKey` 状态测试及 live accessibility tree 的展开/关闭流程交叉验证；下次有真机 VoiceOver 时应补做一次听觉焦点确认。
