# 十五日六维自测 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this approved plan task-by-task.

**Goal:** 实现已确认的六维各十题、七档程度性自测，十五个自然日周期与最多十分的滚动行动加成。

**Architecture:** 保持已有 0–10 内部存储比例，界面显示 0–100；新增可选快照字段保存问卷版本、答案、自测基线及跳过提醒日期。旧快照不改写，当前基线兼容读取 DimensionProfile.selfRating。任务 XP、金币、收藏与塔罗不参与自测结算。

**Tech Stack:** SwiftUI / SwiftData / Foundation / Swift Testing。

**Spec:** 本轮用户批准的六十题与公式：最新自测分 + min(10, 十五日行动目标完成比例 × 10)，总分封顶 100。

## Global Constraints

- 新隔离分支 codex/life-state-assessment，基于 main 1602449；不写主工作区或其他 worktree，不推送、不合并、不删除 worktree。
- 完整测试、独立 Debug 构建和 iPhone 17 Pro 人工验收延后；本轮只执行相关规则、持久化、展示状态测试。
- 每维每天至少一条有效完成算一个行动日；目标为 ceil(clamp(每周目标,1...7) × 15 / 7)。XP 为零也计入，撤销移除，过期回落，未来记录排除。
- 第十五个本地自然日零点开放自测；保存时重新检查。跳过仅抑制当期提示，不改变资格、基线或提交日期；十五日后再次提示，开放后一直可手动补测。
- 答案 0...6，未知/不适用独立，全部六十题必须作出选择；每维至少一个有效答案才能算平均。七档没有默认答案。
- 全部不适用不生成中间分，不覆盖旧基线。每次保存一次原子提交、失败保留答卷。
- 新快照保存原始答案和未重复加成的自测基线，历史快照原值保留。
- 首页解释“自测基线 + 最近十五天行动”，显示更新/跳过、上次日期、当前与基线；完成后显示行动天数和实际分值变化。Reduce Motion、Dynamic Type、VoiceOver 保持可用。

## Review Focus

1. 时区/夏令时/午夜窗口与十五日资格一致；前台和系统时间改变刷新。
2. 旧磁盘存档升级、重开后历史和 XP/金币/收藏/待领取/未查看仍保留。
3. 同日重复任务、零 XP、撤销与过期正确，不受每日 XP 上限影响。
4. 跳过和提前/重复提交不改变已存状态；真实保存失败不污染 UI 上下文。
5. 不适用、未回答、后台恢复、快速连点、节点已到满分仍有真实行动反馈。
