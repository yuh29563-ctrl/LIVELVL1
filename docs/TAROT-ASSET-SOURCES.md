# Rider–Waite–Smith tarot asset sources

The Daily Tarot interface uses scans of the original 1909 Rider–Waite–Smith deck illustrated by Pamela Colman Smith. The imported files are limited to the 22 Major Arcana cards and the original roses-and-lilies card back.

## Major Arcana

- Source collection: [Rider-Waite-Smith tarot deck (TaionWC)](https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC))
- File naming on Wikimedia Commons: `RWS Tarot 00 Fool.jpg` through `RWS Tarot 21 World.jpg`
- App asset names: `TarotRWS00` through `TarotRWS21`

## Card back

- Source file: [Waite–Smith Tarot Roses and Lilies cropped.jpg](https://commons.wikimedia.org/wiki/File:Waite%E2%80%93Smith_Tarot_Roses_and_Lilies_cropped.jpg)
- App asset name: `TarotRWSBack`

The source pages identify these scans as public-domain reproductions of the original deck. Preserve the original image files and this provenance record when replacing or optimizing asset packaging.
